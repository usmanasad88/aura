Abstract

Proactive robotic assistance in human–robot collaboration (HRC) requires systems that can perceive evolving task contexts, anticipate user needs, and intervene appropriately without disrupting human workflow. We present the Agentic Unified Robotic Assistance (AURA) framework, which couples large language model (LLM) reasoning grounded by Standard Operating Procedures (SOPs) with a modular layer of specialized Intent, Motion, Perception, Sound, Affordance, and Performance monitors that supply structured context to a central decision-making module, making the framework reconfigurable and auditable without retraining or re-prompting. We introduce a human-in-the-loop teleoperation data collection methodology and an offline evaluation scheme with an Appropriateness Score (A-Score) tailored to proactive intervention timing, and release a benchmark dataset of annotated multimodal HRC episodes.

Overview

AURA is a modular, event-driven architecture centered on a decision-making Brain coordinating specialized monitors. Its design follows three principles: separation of concerns between perception, reasoning, and action; explainability through inspectable decision rationale; and SOP grounding, where domain knowledge constrains LLM reasoning. The runtime is a LangGraph state machine executing a continuous sense → decide → act loop over a shared Semantic Scene Graph (SSG), grounded by task-specific configuration (a DAG derived from the task SOP, a state schema, a robot-skill catalogue, and an initial scene description).

The framework adopts a neuro-symbolic approach: the VLM acts as a reasoner constrained by a symbolic Directed Acyclic Graph (DAG), so the system delivers both proactive assistance and procedural compliance. Because the architecture is a composition of interchangeable monitors, newer vision-language, segmentation, or pose-estimation models can be substituted as they emerge — without retraining a monolithic policy. The robot side (UR5 + Robotiq 2F-85, cuRobo planner, Quest/SpaceMouse teleop, Isaac Sim digital twin) lives in the companion ur_ws repository.

Contributions

  1. AURA framework — an agentic architecture for proactive robotic assistance integrating real-time multimodal perception with LLM-based reasoning, grounded by SOPs as domain-specific constraints.
  2. Monitor-based architecture — specialized Intent, Motion, Perception, Sound, Affordance, and Performance monitors continuously inform a central decision-making module, enabling explainable, context-aware decisions.
  3. Appropriateness Score (A-Score) — a metric grading each intervention by how well its timing and action match the ground truth, penalising predictions made during expected wait periods, validated on a synthetic adversary suite.
  4. Human-in-the-loop teleoperation methodology — a method for capturing ground-truth recordings of proactive assistance, encoding expert judgment on intervention timing and action selection.
  5. Annotated benchmark dataset — synchronized multimodal episodes (workspace video, robot wrist camera, robot joint states) with annotated intervention events for reproducible evaluation.
  6. Offline evaluation pipeline — processes recorded data through the framework and compares predicted interventions against human ground truth for quantitative performance metrics.
